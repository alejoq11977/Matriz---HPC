# Computación de Alto Rendimiento — Multiplicación de Matrices

Este repositorio contiene el desarrollo, análisis y optimización progresiva de un programa para la multiplicación de matrices cuadradas ($N \times N$) escrito en **C**. 

El objetivo principal es tomar una implementación secuencial base y aplicar de forma incremental diversas técnicas de **Computación de Alto Rendimiento (HPC)** para analizar su impacto en el rendimiento, el uso de memoria y la eficiencia de procesamiento.

---

## 📌 Estructura y Evolución del Proyecto

El proyecto se desarrolla de manera modular a través de múltiples ramas (*branches*), donde cada una representa una etapa específica en el proceso de optimización del algoritmo.

| Rama / Branch | Descripción y Estado | Enfoque Principal |
| :--- | :--- | :--- |
| **`main`** | **Rama Principal** *(Estás aquí)* | Visión general del proyecto, índice y documentación central. |
| `version-inicial` | **Versión Inicial Base** | Implementación clásica secuencial ($O(N^3)$) con asignación dinámica de memoria y lectura de parámetros por CLI. |

---

## 🚀 Guía de Navegación por Ramas

Para revisar el código fuente, la documentación específica y los experimentos de cada fase, puedes cambiar de rama en el repositorio local o mediante la interfaz de GitHub.
